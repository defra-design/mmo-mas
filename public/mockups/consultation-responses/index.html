Consultation responses mockups

While a case is in consultation, the caseworker needs to see who has responded, read the advice and the public's comments as they come in, and extend the deadline if a consultee asks for more time (ML-1712).

The responses come from the consultation service on CDP, so they are shown read-only in a new Consultation responses tab, like the application. Extending the deadline is something the caseworker does, so it is an optional task.

They all use MLA/2026/10006, Hayling Island groyne repairs, with the application from the GOV.UK prototype. Use the bar at the top of each mockup to switch the scenario, and on the tab, its layout. The bar sits outside the case, so it can be left out of screenshots.

How extending the deadline works

The task starts as Optional. Before any extension, the top of the task shows:

  • Consultation started
  • Consultation period
  • Consultation deadline

To extend, the caseworker selects Add extension on the Extensions subgrid. This opens a new page showing the current deadline. That is the original deadline for the first extension, or the latest deadline after that. The caseworker chooses how many days to extend by, in blocks of 7, and the new deadline is shown straight away. They must give a reason. They don't record who asked, as the caseworker may decide to extend without being asked.

Once there is an extension, the top of the task changes to show:

  • Consultation started
  • Original consultation period
  • Original consultation deadline
  • Total extension – all extensions added together
  • Extended consultation deadline

"Original" only appears once there is something to compare it with. In D365 a field's label can't change, so these are separate fields, shown and hidden by a business rule depending on whether there are any extensions.

Each extension is a row in the Extensions subgrid, showing when it was made, how many days it added, the new deadline and the reason. A long reason is cut off, and the full text shows when you hover over it or open the extension. Extensions can't be removed, because each one has already moved the deadline. The deadline can be extended more than once, and after it has passed.

A Power Automate flow updates the case's consultation deadline when an extension is saved. The new deadline applies to every consultee on the case. Consultees are not sent a notification, so the caseworker lets them know.

After the first extension, the task's status changes from Optional to Extended. It can still be opened to extend again.
