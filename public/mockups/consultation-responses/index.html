Consultation responses mockups

While a case is in consultation, the caseworker needs to see who has responded, read the advice and the public's comments as they come in, and extend the deadline if a consultee asks for more time (ML-1712).

The responses come from the consultation service on CDP, so they are shown read-only in a new Consultation responses tab, like the application. Extending the deadline is something the caseworker does, so it is an optional task.

Both use MLA/2026/10006, Hayling Island groyne repairs, with the application from the GOV.UK prototype. Use the bar at the top of each mockup to switch the layout and scenario. The bar sits outside the case, so it can be left out of screenshots.

What the mockups show

  • The tab has two layouts: everything on one page, or a nav with a page for each consultee, as on Marine plan policies and Other permissions.
  • Only requests for advice can be outstanding or overdue. A response to an application notification is optional.
  • The task has two layouts: the extension fields on the task itself, or an Extensions subgrid where Add extension opens a quick create form.
  • The case is laid out like MLA/2026/10015: a full-width Tasks tab first, then Case summary, then Consultation responses, so the new tab is in view rather than in the overflow menu.
  • The task opens from the bottom of the Tasks subgrid, where it shows as Optional. The other tasks and the marine plan policies show as Done because the case is in consultation.

D365 notes

  • Saving an extension needs a Power Automate flow to change the case's consultation deadline. With the fields on the task, the flow would also create the extension record and clear the fields.
  • Showing the new deadline as soon as Extend by is picked needs a small form script. Without one, it would only appear after saving.
  • On the task, the extension fields are only required once one of them is filled in (a business rule), so the task can be opened and closed without extending.

Questions to answer

  • Does an extension also apply to public comments? In the mockups, public comments still close on the original date.
  • Is an extension added to the current deadline, or to today's date when the deadline has already passed? The mockups add it to the current deadline.
  • Will CDP send response statuses back to D365, so the case list can show outstanding or overdue advice?
